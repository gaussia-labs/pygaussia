## Architecture — Core Pipeline (Template Method)

```
Retriever.load_dataset() → list[Dataset] | Iterator[Dataset] | Iterator[StreamedBatch]
    ↓
Gaussia._process()           # base class orchestrates
    ↓
Metric.batch(session_id, context, assistant_id, batch, language)  # subclass implements
    ↓
self.metrics.append(...)     # accumulate results
    ↓
on_process_complete()        # optional aggregation hook
```

### Adding a new metric (checklist)
1. Create `src/gaussia/schemas/<metric>.py` — Pydantic result models
2. Create `src/gaussia/metrics/<metric>.py` — subclass `Gaussia`, implement `batch()` + `on_process_complete()`
3. Create `tests/metrics/test_<metric>.py` — TDD, mock Judge/Guardian
4. Add optional extras group in `pyproject.toml` if new deps needed

## Statistical Modes (src/gaussia/statistical/)

- **FrequentistMode** — point estimates, mean, total variation distance
- **BayesianMode** — bootstrap CI (mc_samples=5000, ci_level=0.95), returns {mean, ci_low, ci_high}

Both implement `StatisticalMode` ABC. Pass as constructor arg to any metric.

## LLM Judge (src/gaussia/llm/)

- **`judge.py`** — `Judge(model, use_structured_output, ...)` → `check(system_prompt, query, data, schema)`
- **`prompts.py`** — Jinja2 templates per metric (context, conversational, bestof, humanity, regulatory, vision)
- **`schemas.py`** — Pydantic output models (`ContextJudgeOutput`, `ConversationalJudgeOutput`, etc.)

## Test Patterns

- Fixtures live in `tests/fixtures/mock_data.py` + `tests/fixtures/mock_retriever.py`
- Mock Judge and Guardian via `unittest.mock.MagicMock`
- Markers: `slow`, `integration`, `unit`, `requires_gpu`, `requires_api_key`
- Coverage minimum: 50% (branch coverage tracked)
- TDD: tests must FAIL before implementation

## Design Rules (non-negotiable)

- **SOLID** strictly enforced — no god classes, no long if/elif chains
- **No string-driven behavior** — use Strategy/Polymorphism
- **No speculative abstractions** — only what the task requires
- **No commented-out code, no section dividers**
- **Minimal comments** — only explain *why*, never *what*
- **mypy strict** on all new code
